# Politique open source

SITUS est un protocole ouvert.

## Ouvert, pour de bon

Sous licence MIT :

- le primitive (`licence active → copie`)
- les 4 usages (`capture`, `train`, `sim`, `deploy`)
- les gabarits de licence, inventaire, agent, juge, scénario
- le schéma `schema/lieu.v0.json`
- les rubriques de test
- la méthode de hash du scan

Ce socle reste public. Un standard de droits fermé n’est pas un standard.

## Fermé par défaut (vie privée, pas le code)

- scans 3D de lieux réels
- adresses, photos de façade, consentements nominatifs
- dialogues avec de vrais clients

Ces fichiers n’appartiennent pas au protocole. Ils appartiennent à l’owner du lieu.

## Plus tard, optionnel

Un service (app owner, matching lab ↔ lieux, hébergement, assurance) peut être un produit à part.
La spec, elle, ne redevient pas propriétaire.

## Pas de token dans ce dépôt

v0 n’a pas de ticker. Si un instrument économique apparaît un jour, il s’appuie sur ce protocole ouvert — il ne le remplace pas.
