# Quittance

Reçu signé après un `allow` / `urgent`.  
Le lab le range. L'owner peut le révoquer sans effacer l'historique.

```
autoriser allow  →  quittance (id, empreinte, usage, lab, emise_at, sig)
```

Hors carte : message client, path, owner, splat.
Schéma : [`schema/quittance.v0.json`](schema/quittance.v0.json)
